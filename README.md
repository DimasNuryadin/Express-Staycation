# Express-Staycation
This project is the backend of the Top Up Game in the BuildWithAngga course class, for the frontend, see the following link:
[React-Staycation](https://github.com/DimasNuryadin/React-Staycation)

## Getting Started

First install modules
```bash
npm install
```

.env file configuration
```bash
MONGO_URL=mongodb://localhost:27017/db_staycation
```

Run the development server:
```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:4001](http://localhost:4001) with your browser to see the result.
